Chess Detection

Computer Vision · Object Detection · Image Processing

Chess Detection explores the problem of extracting a structured chess position from visual information. The project focuses on detecting a chessboard in an image and transforming visual information into a digital representation of the board, combining image processing with object-detection techniques and experiments involving YOLO-based detection.

The interesting part is the transition from raw pixels to structured information: instead of treating an image as an isolated visual input, the goal is to recover a representation that can be interpreted programmatically as a chess position — a practical example of computer vision bridging visual perception and symbolic data.

02

Audio Denoising Autoencoder

Deep Learning · Representation Learning · Signal Processing

This project investigates the use of autoencoders for audio denoising. The central idea is to train a neural network to learn a compact representation of an audio signal and reconstruct a cleaner version from noisy input, learning a transformation from corrupted signals to reconstructed signals rather than an explicit noise-removal rule.

It explores the connection between representation learning and signal reconstruction — a useful example of deep learning applied beyond conventional image and tabular datasets. Experiments are implemented in Python notebooks, focused on the architecture and behaviour of the denoising pipeline.

Convolutional Clustering

Unsupervised Learning · Clustering · Pattern Recognition

Convolutional Clustering explores how convolution-inspired operations can be used in an unsupervised learning setting. The project investigates the structure of patterns in data and compares convolutional clustering ideas with more traditional clustering techniques such as DBSCAN.

Rather than starting from labelled examples, it focuses on how meaningful structure can emerge directly from the geometry and local relationships within the data, using synthetic patterns and datasets designed to highlight the differences between conventional and convolution-based approaches.

04

Soccer ML Analysis

Machine Learning · Sports Analytics · Statistical Modelling

Soccer ML Analysis applies data-driven methods to football analytics. One of the main components focuses on Expected Goals (xG), modelling the probability that a shot results in a goal based on the available characteristics of the chance.

The project also investigates the Ballon d'Or through a statistical and data-analysis perspective, using football data to explore how individual performance can be analysed quantitatively — an example of converting a familiar real-world domain into measurable variables, models and statistical questions.

05

Panggang Game

Python · Flask · JavaScript · Game Development

Panggang is a customizable N-in-a-row strategy game built around a dynamic web interface. The project combines a Python/Flask backend with browser-side interaction and configurable game rules — players can work with large boards, choose the number of consecutive pieces required to win, and generate structured obstacle patterns.

Beyond the game itself, it demonstrates the transition from an algorithmic idea to a complete interactive application, including game logic, backend routing and a browser-based interface — a different side of my interests: systems that are computationally interesting and directly interactive.
