## 🚀 Featured Projects

### ♟️ [ChessDetection](https://github.com/MarcoLorenzetti/ChessDetection)

**Computer Vision · Object Detection · Image Processing**

A project focused on **detecting chessboards and digitally reconstructing chess positions from images**.

The repository combines image-based analysis, chessboard detection and a structured representation of the detected board, with dedicated notebooks and YOLO-related files.

→ [Explore the project](https://github.com/MarcoLorenzetti/ChessDetection)

---

### 🔊 [Audio-Denoising-AutoEncoder](https://github.com/MarcoLorenzetti/Audio-Denoising-AutoEncoder)

**Deep Learning · Autoencoders · Audio Processing**

An experiment in **neural audio denoising using autoencoders**, exploring how representation learning can be used to reconstruct cleaner signals from noisy audio.

The repository contains Jupyter notebooks dedicated to the denoising architecture and experiments.

→ [Explore the project](https://github.com/MarcoLorenzetti/Audio-Denoising-AutoEncoder)

---

### 🧩 [Convolutional-Clustering](https://github.com/MarcoLorenzetti/Convolutional-Clustering)

**Unsupervised Learning · Clustering · Machine Learning**

An exploration of **Convolutional Clustering**, including experiments and comparisons with traditional clustering approaches such as **DBSCAN**.

The project includes a Python implementation, synthetic patterns and several datasets used to investigate the behaviour of the method.

→ [Explore the project](https://github.com/MarcoLorenzetti/Convolutional-Clustering)

---

### ⚽ [Soccer-ML-Analysis](https://github.com/MarcoLorenzetti/Soccer-ML-Analysis)

**Machine Learning · Sports Analytics · Statistical Modeling**

A data-driven analysis of football focused on two tasks:

* **Expected Goals (xG) modeling**
* **Ballon d'Or analysis**

The project is implemented through reproducible Jupyter notebooks and includes the data-processing workflow required for the analyses.

→ [Explore the project](https://github.com/MarcoLorenzetti/Soccer-ML-Analysis)

---

### 🎮 [Panggang-Game](https://github.com/MarcoLorenzetti/Panggang-Game)

**Python · Flask · JavaScript · Game Development**

A customizable **N-in-a-row strategy game** built with Flask.

Players can configure large boards, choose the winning sequence length and generate structured obstacle patterns. The project combines game logic on the backend with a dynamic browser-based interface.

→ [Play with the code](https://github.com/MarcoLorenzetti/Panggang-Game)
